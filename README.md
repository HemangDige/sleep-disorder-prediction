# Sleep Disorder Prediction 😴

## Overview
Predicting sleep disorders (None, Insomnia, Sleep Apnea) 
using machine learning on patient health and lifestyle data.

---

## Results
| Model | Test Accuracy | F1 Score |
|-------|--------------|----------|
| Decision Tree | 94.67% | 92.14% |
| **Random Forest** | **94.67%** | **92.14%** |
| Gradient Boosting | 94.67% | 92.14% |
| Logistic Regression | 93.33% | 91.94% |
| SVM | 92.00% | 88.81% |

✅ Best Model: Random Forest — 94.67% accuracy

---

## Top Features
1. Systolic Blood Pressure
2. BMI Category
3. Diastolic Blood Pressure
4. Sleep Duration
5. Age
